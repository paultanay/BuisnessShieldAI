# Security Policy

BusinessShield is open source, but exploitable security issues should be reported responsibly so users have a chance to patch before details are widely shared.

## Reporting

Use public GitHub issues for normal bugs, documentation issues, feature requests, and non-sensitive security hardening ideas.

Please use GitHub Security Advisories for issues that could expose data, bypass authentication, leak secrets, escalate privileges, or compromise deployments.

## Current Status

BusinessShield is pre-release software maintained by a solo maintainer. Security fixes are applied to the main branch until stable releases are introduced.

## Scope

Security reports may include authentication, authorization, tenant isolation, API key handling, secret exposure, dependency risk, or scanner behavior that could leak private data.

BusinessShield is not legal advice, and legal interpretation disagreements are not treated as security vulnerabilities.
